# 데이터 안내

이 프로젝트는 공공 생활인구와 복지 관련 통계를 결합하여 자치구 단위의 수요 지표를 산출합니다.
원본 데이터는 라이선스 또는 배포 제한 가능성이 있어, 본 레포에서는 재현에 필요한 범위로만 공개합니다.

## 1) 데이터 공개 범위
- 원본 데이터 원문 파일: 공개하지 않음
- 공개하는 자료
  - 전처리 기준과 집계 규칙 설명
  - 공개 가능한 형태의 집계 결과 또는 샘플 데이터 선택 사항
  - 지표 산출 결과 요약 선택 사항

## 2) 사용 데이터 요약
- 핵심 데이터: 생활인구 데이터
  - 기간: 2023년 1년치
  - 공간 단위: 서울특별시 25개 자치구 집계
  - 시간 단위: 0시부터 23시 시간대 포함
  - 출처: 서울특별시 열린데이터광장 또는 공모전 제공 데이터셋
- 보조 데이터: 고령자 현황, 노인여가복지시설, 노인의료복지시설, 노인재가복지시설 통계
  - 기준연도: 2023년
  - 출처: 공공데이터 또는 공모전 제공 자료

## 3) 전처리 및 집계 규칙
- 결측 및 이상치 처리
  - 기준: 결측은 제외 후 집계하거나 대체값 처리 후 집계
- 행정구역 기준
  - 기준: 자치구 코드 정합성 확인 후 통일
- 기간 정렬
  - 기준: 1년치를 요일 기준 평균으로 집계하여 대표값 생성
- 파생 지표 생성
  - 표준화: Z-Score 기반 표준화 적용
  - 분석 프레임: 수요지수, 공급지수, 인구 활력도

## 4) 이 레포에 포함된 데이터 파일
- `data/processed/` 선택 사항
  - 추후 공개 가능한 범위를 확정한 뒤 업데이트합니다.
- `data/sample/` 선택 사항
  - 추후 공개 가능한 범위를 확정한 뒤 업데이트합니다.

## 5) 재현을 위한 안내
- 원본 데이터는 아래 중 한 방법으로 준비합니다.
  1) 공모전 제공 데이터
  2) 공개 포털에서 동일 항목 다운로드
- 원본 데이터를 준비하신 경우, 아래 경로에 배치한다고 가정합니다.
  - `data/raw/` : 원본 파일 위치 선택 사항
  - 또는 노트북에서 직접 경로 지정

## 6) 비고
- 원본 데이터의 배포 제한이 있는 경우, 본 레포는 분석 로직과 집계 기준 중심으로 재현 가능하도록 구성합니다.
