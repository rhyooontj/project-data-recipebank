# 데이터 안내

본 프로젝트는 생활인구와 노인 복지 관련 통계를 결합해 자치구 단위 수요 지표를 산출합니다.
원본 데이터는 배포 제한 가능성이 있어 레포에는 포함하지 않았습니다.

## 공개 범위
- 원본 파일: 미포함
- 포함 내용
  - 데이터 출처와 사용 범위
  - 전처리 및 집계 기준
  - 공개 가능한 형태의 샘플 또는 집계 결과 선택 사항

## 사용 데이터 요약
- 생활인구 데이터
  - 기간: 2023년 1년
  - 단위: 서울시 25개 자치구 집계
  - 시간: 0시부터 23시 포함
  - 출처: 서울시 열린데이터광장 또는 공모전 제공 데이터
- 보조 통계
  - 고령자 현황
  - 노인여가복지시설
  - 노인의료복지시설
  - 노인재가복지시설
  - 기준연도: 2023년
  - 출처: 공공데이터 또는 공모전 제공 자료

## 전처리 및 집계 기준
- 결측과 이상치: 제외 또는 대체 처리 후 집계
- 행정구역: 자치구 코드 기준으로 정리 후 통일
- 기간 처리: 1년치를 요일 기준 평균으로 집계해 대표값 생성
- 지표 산출: Z-Score 표준화 적용, 수요지수, 공급지수, 인구 활력도 프레임 사용
